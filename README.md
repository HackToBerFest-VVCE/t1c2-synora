# BillSense — Explain the Unexpected Bill

BillSense helps users understand unexpected electricity bill increases by comparing billing periods, electricity consumption, and household changes.
It uses Python and Streamlit to provide an interactive bill analysis experience.
Snowflake stores bill records to support bill history and data retrieval.
PDF text extraction and OCR help process uploaded electricity bills.
Our goal is to make electricity bills easier to understand through transparent, evidence-based explanations.
